# 디자인 및 사운드 자산

- `assets/toys/`: 이 프로젝트를 위해 AI로 생성한 투명 PNG 5종. 표정은 캐릭터 PNG에 포함되어 있으며 파츠를 별도로 그립니다. 얼굴 위에 안경 같은 추가 표정은 그리지 않습니다.
- `assets/parts/`: Unicode 이모지를 담은 SVG 12종. 웹페이지의 파츠는 동일한 문자로 직접 렌더링합니다. 독자적으로 그린 파츠 일러스트는 아니며, 표시 모습과 이용 조건은 해당 플랫폼의 이모지 글꼴에 따릅니다. 글꼴 파일을 포함하거나 재배포하지 않습니다.
- `assets/audio/`: 프로젝트 전용 절차적 합성 WAV 4종. 24 kHz, mono, 16-bit PCM. 각 0.22–0.48초. 외부 음원 샘플을 사용하지 않았습니다.
- UI: CSS 기반 파스텔 배경과 체크 패턴, 시스템 한국어 글꼴. 별도 웹폰트 요청 없음.
- 원본 참고 이미지는 완성 ZIP에 포함하지 않았습니다.

코드와 생성 자산은 이 웹페이지의 수정과 활용을 위해 함께 제공합니다. AI 생성물에 독점적인 저작권이 보장된다는 의미는 아닙니다.
