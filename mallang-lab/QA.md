# 확인 기록

## 확인한 항목

- JavaScript 문법 검사: app.js / soft-body.js.
- 로컬 웹서버 HTTP 200, 브라우저 초기 화면 및 말랑이 그림 표시.
- 수정 후 브라우저에서 드래그 입력과 터치 횟수 변경, 실행 오류 로그 없음.
- 390px 화면에서 문서 가로 넘침 없음, PNG 이미지 모두 로드.
- 말랑이 구성 API: 고양이 + 파츠 6개 적용 후 화면의 레시피와 3단계 표시 확인. 잘못된 종류 입력 거부 확인.
- 변형 엔진 자동 검사: 가장자리 누름 약 93px 변형, 160px/150px 드래그에서 최대 약 218px 변형, 반대쪽 평균 변형 약 7px(800×720 내부 좌표 기준).
- 두 접점 당김, 반복 입력에서 유한 좌표 유지; 손을 뗀 뒤 감쇠 진동과 원형 복원 검사 통과.
- WAV의 형식·길이 및 ZIP 내부 파일 손상 여부 검사.

## 한계

- iPhone/Android 실제 기기와 두 손가락 입력은 실물 기기에서 확인하지 못했습니다. 두 접점 처리는 엔진 수준에서 검사했습니다.
- 실제 스피커/이어폰으로 효과음의 청감과 모든 브라우저의 다운로드 동작까지 확인한 것은 아닙니다.
- 2D 스프링 메시 기반 변형입니다. 완전한 3D 젤리/유체 물성 시뮬레이션은 아닙니다.
- WebGL 사용 불가 시 Canvas 2D 삼각형 변형으로 대체합니다. 구형 기기에서는 성능이 낮을 수 있습니다.
