# 말랑이 이상연구소 · J LAB

이번 버전은 눈이 짝짝이고 비율이 어긋난 병맛 캐릭터 5종으로 구성했습니다. 귀여운 캐릭터가 아니라, 조금 못생겼는데 계속 보게 되는 방향의 새 일러스트를 사용합니다.

첨부 참고 이미지의 파스텔 색감과 조작 아이디어를 바탕으로 제작한 반응형 웹페이지입니다.

## 바로 실행하기

1. ZIP을 먼저 **모두 압축 해제**합니다.
2. `index.html`을 Chrome 또는 Edge에서 엽니다.
3. 말랑이를 선택 → 파츠를 선택 → **이대로 만들기**를 누릅니다.
4. 말랑이를 손가락이나 마우스로 누르고 움직여 보세요.

설치, 로그인, 인터넷 연결, API 키가 필요하지 않습니다. 폴더 구조를 그대로 유지해 주세요. 휴대폰에서는 파일 앱의 미리보기 대신 웹브라우저로 열거나 정적 웹호스팅에 폴더를 올려 접속하세요.

## 들어 있는 기능

- 말랑이 5종: 복숭아, 푸딩, 구름, 고양이, 딸기 찹쌀떡
- 파츠 12종, 최대 24개, 과일/러블리/비즈 필터, 랜덤 조합, 개별 삭제
- 톡 누르기, 길게 누르기, 좌우 문지르기, 연속 터치
- 누르는 동안 귀여운 표정 변화, 말랑한 눌림과 복원, 위로 당기기
- 터치 위치와 이동 방향에 반응하는 파츠, 간단한 중력·충돌·튕김
- 크런치, 팝, 비즈, 스퀴시 효과음 / 음소거와 음량 조절
- 내 말랑이를 PNG 이미지로 저장
- 키보드: 말랑이에 Tab으로 이동해 Space 또는 Enter로 누르기
- PC 2열 / 모바일 1열 화면

조작 방법 버튼은 안내와 반응 강도를 선택합니다. 어느 모드에서든 실제로 오래 누르거나 드래그하면 그 동작을 인식합니다. 웹에서 표현한 시각·청각 시뮬레이션으로 실제 촉감이나 진동은 제공하지 않습니다. 멀티터치를 지원하며 두 손가락으로 다른 곳을 잡아당길 수 있습니다. 누른 위치별로 몸체·표정·파츠가 함께 휘고, 손을 놓으면 감쇠 진동으로 복원됩니다.

## 소리

브라우저의 자동 재생 정책에 따라 첫 클릭 또는 터치 후 소리가 활성화됩니다. 기기 음량과 페이지 상단의 소리 버튼도 확인해 주세요. `assets/audio/`의 WAV는 이 프로젝트를 위해 합성한 효과음으로, 실제 말랑이 녹음은 아닙니다.

| 파일 | 내용 |
|---|---|
| crunch.wav | 짧고 바삭한 잡음 조각 |
| pop.wav | 과일·하트의 톡 터지는 소리 |
| glass.wav | 비즈·보석의 맑은 부딪힘 |
| squish.wav | 저음의 부드러운 눌림 |

직접 파일로 열어도 소리가 나도록 동일 WAV를 `sounds.js`에도 포함했습니다. 말랑이 그림도 이미지 저장 시 브라우저 보안 제한을 피하도록 `toys.js`에 포함했습니다.

## 파일 구성 / 수정하기

```text
index.html               화면과 한국어 문구
style.css                색상, 배치, 모바일 화면
app.js                   선택, 파츠, 표정, 소리, PNG 저장
soft-body.js             국소 눌림·당김·멀티터치·스프링 메시 렌더링
assets/toys/*.png        투명 배경 말랑이 5종
assets/toys/toys.js      오프라인 캔버스용 이미지 묶음
assets/parts/*.svg       이모지 기반 파츠 12종
assets/audio/*.wav       효과음 4종
assets/audio/sounds.js   오프라인 소리 묶음
tools/rebuild-bundles.py PNG/WAV 변경 후 묶음 재생성
ASSETS.md               자산 설명
QA.md                   확인 범위와 제한
```

외부 프레임워크나 패키지 없이 HTML/CSS/JavaScript로 구성했습니다. 파츠 종류와 말랑이 이름은 `app.js` 앞부분의 `parts`, `toys`에서 수정합니다. 소리와 이미지를 교체했다면 Python 3으로 `python tools/rebuild-bundles.py`를 실행해 포함 묶음을 갱신하세요. 실행 자체에는 Python이 필요하지 않습니다.

웹에 공개하려면 `index.html`이 있는 폴더의 내용을 정적 호스팅의 루트에 업로드하세요. 본 납품물은 요청하신 ZIP이며 외부 서버에 게시하지 않았습니다.

## 참고

새로고침하면 선택과 터치 횟수가 초기화됩니다. 파츠는 운영체제의 컬러 이모지로 표시하므로 Windows, Android, iOS에서 모양이 조금 다릅니다. 생성 그림은 참고 이미지와 동일한 원본이 아니라 새로 만든 일러스트입니다.
