# 말랑이 연구소

압축을 풀고 index.html을 열면 바로 실행됩니다. 설치와 빌드는 필요 없습니다.

시작 썸네일 → 말랑이 선택 → 파츠 선택 → 만지기 순서입니다. 모바일에서는 단계별로 한 화면만 보이며, PC 선택 단계에서는 말랑이 미리보기가 함께 보입니다. 홈 버튼을 누르면 시작 화면으로 돌아갑니다.

말랑이를 누르고 당기거나 문질러 보세요. 소리는 첫 터치 후 재생되며 음량 조절과 음소거를 지원합니다. 만지는 영역에서는 텍스트 선택과 길게 누르기 메뉴를 막았습니다.

## 웹에 올리기와 카카오톡 공유

폴더 전체를 정적 웹 호스팅에 올리세요. 시작 화면과 공유 미리보기에는 assets/og-thumbnail-mallang.png를 사용합니다.
배포할 주소를 안다면 Python으로 `python tools/set-share-url.py https://실제주소/경로/`를 실행한 후 업로드하세요. OG 이미지 주소와 페이지 주소가 절대 주소로 설정됩니다.

친구한테 공유하기 버튼은 기기 공유 메뉴를 열며, 지원하지 않는 브라우저에서는 링크를 복사합니다. 링크에는 선택한 단계나 파츠를 붙이지 않으므로 친구는 항상 첫 화면을 봅니다. PC 파일 실행 및 localhost 주소는 친구가 접속할 수 없어 안내 문구를 표시합니다. 카카오톡 미리보기는 공개 HTTPS 주소가 필요하고, 기존 링크 이미지는 캐시로 인해 갱신에 시간이 걸릴 수 있습니다.

## 파일

index.html: 단계 구성 및 공유 메타데이터
style.css: 모바일 및 PC 레이아웃
app.js: 선택, 오디오, 공유, 터치 및 렌더링
soft-body.js: 말랑이 변형 물리
assets/: 캐릭터 PNG, 썸네일, 파츠 SVG, 효과음 WAV와 오프라인 번들
