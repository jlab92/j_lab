# 캠퍼제이 답방 매니저 (브라우저 확장 버전)

네이버 블로그 **전체 공개 게시글 URL**을 입력하면 모바일 페이지의 제목 및 본문 텍스트를 읽어 **키워드 기반 댓글 초안**을 만듭니다. 네이버 계정에 로그인하거나 댓글을 자동 등록하지 않습니다.

## 설치 (웨일/크롬, 최초 1회)
1. 이 폴더의 파일 3개 `manifest.json`, `popup.html`, `popup.js`를 같은 폴더에 다운로드합니다.
2. 크롬 주소창에 `chrome://extensions` 또는 웨일 주소창에 `whale://extensions` 입력.
3. **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 해당 폴더 선택.
4. 브라우저 도구 모음에서 **캠퍼제이 답방 매니저** 아이콘을 클릭합니다.
5. 공개 게시글 URL을 넣고 **공개 글 불러오기**를 누릅니다.

## 한계와 개인정보
- 공개 글이라도 네이버 접근 제한, 임시 오류, 구조 변경에 따라 불러오지 못할 수 있습니다.
- 네이버의 공식 API가 아니고, 허용된 공개 페이지를 개별 요청합니다. 대량 자동 수집·댓글 자동 작성은 하지 않습니다.
- 이 버전은 AI가 아니라 키워드 기반 추천입니다. 불러온 글과 댓글이 맞는지 직접 확인하세요.
- 최근 답방 기록은 해당 브라우저의 확장 프로그램 로컬 저장소에만 기록됩니다.
- 확장 프로그램은 `blog.naver.com`, `m.blog.naver.com`에만 접근 권한을 요청하며 수집한 글 내용을 외부 AI 서비스로 전송하지 않습니다.

## v1.2 현재 글 자동 읽기
- 네이버 블로그 게시글을 열고 웨일/크롬의 확장 아이콘을 클릭하면 현재 글의 URL과 공개 본문을 읽으려고 시도합니다.
- 데스크톱 블로그 iframe의 게시글 번호, canonical 주소, og:url 등을 확인합니다.
- 자동 수집이 불가능하면 게시글의 **URL 복사** 링크를 붙여넣고 `주소로 불러오기`를 누르세요.
- 댓글은 규칙 기반 초안으로 자동 작성되며, 실제 글에 맞게 수정하고 직접 게시해야 합니다.

## v1.3 댓글 구체화
- 실제 공개 글 본문에서 구체적인 문장을 추려 댓글 초안에 인용합니다.
- 단순한 주제별 상투적 문구보다 구체적이지만 AI 문맥 이해 기능은 아닙니다.
- 댓글 초안의 인용 문장이 본문과 맞는지 확인 후 직접 등록하세요.

## v1.4 AI 감상 댓글 (선택 기능)
- 기존 무료 댓글 추천 기능은 그대로 사용할 수 있습니다.
- OpenAI API 키를 입력하면 글의 상황에 맞춘 자연스러운 감상 댓글을 작성합니다.
- API 사용은 ChatGPT 구독과 별도 과금됩니다. 네이버 글 본문이 OpenAI API로 전송됩니다.
- 키는 브라우저 세션 저장소에만 보관하며, 공개 저장소 코드나 기록 DB에 넣지 않습니다.
- 생성된 문장이 본문 내용과 맞는지 확인하고 사용자가 직접 네이버에 댓글을 등록해야 합니다.
